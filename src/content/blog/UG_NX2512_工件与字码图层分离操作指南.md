## 一、核心概念与规范

### 1.1 为什么必须分层？

在 UG/NX 加工环境中，刻字曲线与工件实体混放在同一图层会导致以下问题：

| 问题场景 | 后果 |
|---------|------|
| 开粗/精加工选几何体时 | 误选字码曲线，导致刀路异常或撞刀风险 |
| 刻字工序选文本时 | 工件曲面干扰，选不中目标字码 |
| 复杂零件多工序编程 | 图形区混乱，降低选点/选面效率 |
| 后处理仿真 | 字码曲线干扰实体显示，影响仿真判断 |

### 1.2 图层规范建议（企业标准）

| 图层编号 | 对象类型 | 用途说明 |
|---------|---------|---------|
| **1 ~ 10** | 工件实体 / 片体 | 毛坯、成品模型、工装夹具 |
| **11 ~ 20** | 辅助几何 | 基准平面、基准轴、坐标系 |
| **21 ~ 30** | 曲线 / 草图 | 构造线、驱动线、边界 |
| **80** | 字码（备选） | 次要刻字、临时标注 |
| **90** | 字码（主层）⭐ | **正式加工字码统一放置层** |
| **91 ~ 99** | 预留字码层 | 多工序刻字、不同深度字码分组 |

> 💡 **建议**：将 **90 层** 固定为"字码专用层"，写入企业模板文件（*.prt 模板），所有编程人员统一执行。

### 1.3 加工字码的正确形式

| 字码类型 | 创建路径 | 加工适用性 | 推荐度 |
|---------|---------|-----------|-------|
| **曲线文本** ⭐ | 插入 → 曲线 → 文本 | 固定轮廓铣、曲线驱动、平面铣均可识别 | ✅ 强烈推荐 |
| 注释文本（PMI） | 插入 → 注释 → Note | 仅"平面文本""轮廓文本"工序可识别 | ⚠️ 有限适用 |
| 文本特征（拉伸/凸起） | 插入 → 设计特征 → 文本 | 需分解为曲线后才能用于常规刀路 | ❌ 不推荐直接加工 |

> **结论**：CNC 加工刻字优先使用 **【曲线文本】**（插入 → 曲线 → 文本），生成的是纯曲线几何体，可被绝大多数加工工序直接调用。

## 二、方法一：移动至图层（推荐）

适用于：模型已建好，需要将已有字码曲线批量转移到 90 层。

### 2.1 操作步骤

**Step 1：选中所有字码曲线**

- 在图形区框选所有刻字文本（或按住 `Ctrl` 逐一点选）
- 若字码分散，可使用**类型过滤器**：选择条 → 类型过滤器 → 勾选**曲线**（Curve），再框选

**Step 2：调用移动至图层命令**

- 菜单栏：**格式（Format）→ 移动至图层（Move to Layer）**
- 或右键菜单：**右键 → 格式 → 移动至图层**

> 系统首先弹出 **"类选择"（Class Selection）** 对话框，确认已选对象后点击**确定**（或按鼠标中键）。

![](https://p11-flow-imagex-sign.byteimg.com/labis/image/ba4e33d69b7d0fc6577412ba521e4253~tplv-be4g95zd3a-448x448.jpeg?lk3s=8e244e95&rcl=20260730145457C208EE60889C389F1230&rrcfp=b2576990&x-expires=1793170505&x-signature=O91uHclnZgNSkDJy64l26rZ6vmg%3D)


**Step 3：指定目标图层**

- 在弹出的 **"图层移动"** 对话框中，**目标图层**输入 `90`
- 点击 **确定**

✅ 所有选中的字码曲线立即转移到 90 层，原图层不再保留这些对象。

### 2.2 工件移至 1 层（同步操作）

如需将工件几何体统一归到 1 层：

1. 框选所有工件实体/片体（可用类型过滤器筛选"实体"或"片体"）
2. 格式 → 移动至图层
3. 目标图层输入 `1` → 确定

## 三、方法二：Ctrl+J 编辑对象显示（最快）

适用于：快速修改少量对象的图层属性，无需打开多级菜单。

### 3.1 操作步骤

**Step 1：选中字码曲线**

- 单击或框选需要分层的字码曲线

**Step 2：按 Ctrl+J**

- 弹出 **"编辑对象显示"（Edit Object Display）** 对话框

![](https://p3-flow-imagex-sign.byteimg.com/labis/image/9cdd31b8bbc644d0992304788924d66b~tplv-be4g95zd3a-448x448.jpeg?lk3s=8e244e95&rcl=20260730145457C208EE60889C389F1230&rrcfp=b2576990&x-expires=1793170505&x-signature=8WcrXWUtos7J38G7sK9bpaJ5vmU%3D)

**Step 3：修改图层**

- 在对话框中找到 **"图层"（Layer）** 输入框
- 直接填入图层号 `90`
- 点击 **应用（Apply）** 或 **确定（OK）**

> 💡 **优势**：Ctrl+J 不仅可以改图层，还能同时修改颜色、线型、透明度等显示属性。建议将字码统一设为**红色**或**黄色**，与工件几何体视觉区分。

### 3.2 批量修改技巧

- 选中多个对象后按 `Ctrl+J`
- 在图层栏输入 `90` → **应用**
- 对话框不关闭，继续选其他对象修改，效率更高

## 四、事前规划：新建文字直接落在字码图层

适用于：从零开始建模，避免后期整理。

### 4.1 设置工作图层为 90

1. 按 **`Ctrl + L`** 打开 **"图层设置"（Layer Settings）** 对话框
2. 在图层列表中找到 **90** 层
3. **双击 90 层**，或在工作层输入框中输入 `90` 后回车
4. 90 层变为**工作图层（Work Layer）**，对话框关闭

> **工作图层特性**：所有新建对象（包括曲线、实体、文本等）将自动归属当前工作图层。

### 4.2 创建曲线文本

1. 菜单：**插入（Insert）→ 曲线（Curve）→ 文本（Text）**
2. 在 **"文本"** 对话框中设置：
   - **类型**：平面副 / 曲线上 / 面上（根据刻字位置选择）
   - **文本属性**：输入刻字内容、选择字体（推荐单线字体如 `Modern` 或标准 TTF 字体）
   - **锚点位置**：调整文本在放置面上的位置
3. 点击 **确定**

✅ 新生成的字码曲线直接落在 **90 层**，无需后期移动。

### 4.3 建模完成后恢复工作图层

字码创建完毕后，将工作图层切回 **1 层**：

- `Ctrl + L` → 双击 **1 层** → 继续工件建模

## 五、图层显示与隐藏控制

分层后的核心收益：加工编程时快速切换显隐，避免误选。

### 5.1 图层显隐操作

1. 按 **`Ctrl + L`** 打开图层设置
2. 找到 **90 层**
3. **勾选** = 显示该图层所有对象
4. **取消勾选** = 隐藏该图层所有对象

### 5.2 编程场景应用

| 加工阶段 | 图层 1（工件） | 图层 90（字码） | 目的 |
|---------|---------------|----------------|------|
| 开粗（型腔铣） | ✅ 显示 | ❌ 隐藏 | 避免字码干扰选面/选体 |
| 精加工（等高/固定轴） | ✅ 显示 | ❌ 隐藏 | 防止字码曲线被误选为边界 |
| 刻字工序 | ✅ 显示（参考） | ✅ 显示（加工对象） | 字码作为刀路驱动几何体 |
| 清根 / 残料加工 | ✅ 显示 | ❌ 隐藏 | 保持图形区简洁 |
| 后处理 / 仿真 | ✅ 显示 | ✅ 显示 | 完整验证所有工序 |

### 5.3 快速图层隔离技巧

- **只显示字码层**：Ctrl+L → 右键 **90 层** → **设为仅可见（Make Only Visible）**
- **恢复全部显示**：Ctrl+L → 右键任意层 → **全部可见（Make All Visible）**

## 六、加工模块应用

### 6.1 刻字加工工序选择

字码曲线在 90 层后，加工模块中常用以下工序：

| 工序类型 | 适用场景 | 字码选取方式 |
|---------|---------|-------------|
| **固定轮廓铣（Fixed Contour）** | 曲面刻字、3D 浮雕字 | 驱动方法选 **"曲线/点"**，图层过滤只开 90 层，选字码曲线 |
| **平面铣（Planar Milling）** | 平面刻字 | 驱动方法选 **"文本"** 或 **"曲线/点"**，选 90 层字码 |
| **平面文本（Planar Text）** | 简单平面刻字 | 直接选 90 层中的 PMI 注释或曲线文本 |
| **轮廓文本（Contour Text）** | 沿曲面轮廓刻字 | 选 90 层字码作为文本几何体 |

### 6.2 几何体创建避坑

- **创建 MCS / 部件 / 毛坯** 时：
  - 在图层设置中 **隐藏 90 层**
  - 仅选择 1 层中的工件实体作为 **部件（Part Geometry）** 和 **毛坯（Blank）**
  - 避免字码曲线被误识别为加工边界

- **创建刻字工序** 时：
  - 图层设置中 **仅显示 90 层**（或同时显示 1 层作为参考）
  - 快速选中所有字码曲线，无需在复杂工件中逐一寻找

## 七、常见踩坑与解决方案

### 7.1 ❌ 误用制图注释刻字

| 问题 | 说明 |
|-----|------|
| 现象 | 使用"插入 → 注释 → Note"创建的字码，在加工模块中部分工序无法识别 |
| 原因 | PMI 注释属于制图对象，仅"平面文本""轮廓文本"等少数工序支持 |
| 解决 | 改用 **"插入 → 曲线 → 文本"** 创建曲线文本，通用性最强 |

### 7.2 ❌ 文本特征未分解

| 问题 | 说明 |
|-----|------|
| 现象 | 使用"插入 → 设计特征 → 文本"创建的字码，移动图层后特征仍在原层 |
| 原因 | 文本特征属于参数化特征，移动图层仅移动其生成的曲线，特征本体仍留在原图层 |
| 解决 | **编辑曲线 → 分解（Explode）** 或 **抽取曲线** 后，将独立曲线移至 90 层 |

### 7.3 ❌ 字码曲线与实体未区分

| 问题 | 说明 |
|-----|------|
| 现象 | 刻字刀路生成失败，或开粗刀路异常切入字码区域 |
| 原因 | 字码曲线与工件实体在同一图层，选几何体时混淆 |
| 解决 | 严格执行 **1 层（工件）/ 90 层（字码）** 分层规范 |

### 7.4 ❌ 字体选择不当

| 问题 | 说明 |
|-----|------|
| 现象 | 刻字刀路过切、断刀，或字码显示为双线 |
| 原因 | 使用双线 TTF 字体（如宋体、黑体），刻字刀路沿双线中心走，宽度不可控 |
| 解决 | 优先使用 **单线字体**（如 `Modern`、`Arial` 单线版、或专用单线字库） |

### 7.5 ❌ 图层 90 被设为工作图层后忘记切回

| 问题 | 说明 |
|-----|------|
| 现象 | 后续创建的实体、草图全部落在 90 层，导致图层混乱 |
| 解决 | 创建完字码后，立即 `Ctrl+L` 将工作图层切回 **1 层** |

## 九、标准作业流程（SOP）

### 9.1 新建零件时

1. 打开企业模板（已预设 90 层为"字码层"）
2. 确认工作图层为 **1**
3. 正常建模工件几何体

### 9.2 需要刻字时

1. `Ctrl + L` → 双击 **90 层** → 设为工作图层
2. `插入 → 曲线 → 文本` → 创建字码
3. `Ctrl + L` → 双击 **1 层** → 恢复工作图层

### 9.3 已有模型整理时

1. 框选所有字码曲线
2. `格式 → 移动至图层` → 输入 **90** → 确定
3. 框选所有工件实体
4. `格式 → 移动至图层` → 输入 **1** → 确定

### 9.4 加工编程时

1. 进入加工模块
2. `Ctrl + L` → 隐藏 **90 层** → 创建工件几何体（部件/毛坯）
3. 创建开粗/精加工工序
4. `Ctrl + L` → 显示 **90 层** → 创建刻字工序
5. 后处理 / 仿真时全部显示
